KEYCLOAK CONFIGURATION - FULLY EXTERNALIZED
=============================================================================

Configuration Class: KeycloakProperties
Location: application/src/main/java/com/vetclinic/config/KeycloakProperties.java

Properties:
- authServerUrl: Base URL of Keycloak server
- realm: Keycloak realm name
- clientId: OAuth2/OIDC client ID
- clientSecret: OAuth2/OIDC client secret

Environment Variables:
- KEYCLOAK_URL (default: http://localhost:8180)
- KEYCLOAK_REALM (default: vetclinic)
- KEYCLOAK_CLIENT_ID (default: vetclinic-app)
- KEYCLOAK_CLIENT_SECRET (default: vetclinic-secret)

Configuration File (application.yml):
keycloak:
  auth-server-url: ${KEYCLOAK_URL:http://localhost:8180}
  realm: ${KEYCLOAK_REALM:vetclinic}
  client-id: ${KEYCLOAK_CLIENT_ID:vetclinic-app}
  client-secret: ${KEYCLOAK_CLIENT_SECRET:vetclinic-secret}

CORS CONFIGURATION - FULLY EXTERNALIZED
=============================================================================

Configuration Class: CorsProperties
Location: application/src/main/java/com/vetclinic/config/CorsProperties.java

Properties:
- allowedOrigins: Comma-separated list of allowed origins
- allowedMethods: Comma-separated list of HTTP methods
- allowedHeaders: Comma-separated list or "*" for all
- allowCredentials: Whether to allow credentials
- maxAge: Cache duration in seconds

Environment Variables:
- CORS_ALLOWED_ORIGINS (default: http://localhost:3000)
- CORS_MAX_AGE (default: 3600)

Configuration File (application.yml):
cors:
  allowed-origins: ${CORS_ALLOWED_ORIGINS:http://localhost:3000}
  allowed-methods: GET,POST,PUT,DELETE,OPTIONS
  allowed-headers: "*"
  allow-credentials: true
  max-age: ${CORS_MAX_AGE:3600}

Multiple Origins Example:
CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:3001,https://app.example.com

  -e SPRING_PROFILES_ACTIVE=docker \
  -e KEYCLOAK_URL=https://auth.example.com \
  -e KEYCLOAK_REALM=vetclinic \

  -e SPRING_DATASOURCE_PASSWORD=<from_vault> \

=============================================================================
SECURITY NOTES
=============================================================================

1. Client Secrets: NEVER commit actual secrets to code/YAML
   - Always use environment variables in production
   - Consider using Vault, AWS Secrets Manager, or Kubernetes Secrets

2. CORS Origins: Be specific in production
   - Bad: allowed-origins: "*"
   - Good: allowed-origins: https://app.example.com

3. H2 Console: Disabled in non-dev profiles
   - Only enabled by default in development

4. Database Passwords: Use environment variables
   - DB_PASSWORD environment variable
   - SPRING_DATASOURCE_PASSWORD for Spring config
